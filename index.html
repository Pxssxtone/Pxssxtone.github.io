Channels Uploader

Channels Uploader is a private tool used only by its owner, Luca Alberton. It uploads and schedules videos on the owner's own YouTube channels. It is not offered to the public.

Privacy policy

What it accesses. With the owner's permission, the tool uses Google's YouTube Data API and YouTube Analytics API. It uploads videos, sets their titles, descriptions, tags and schedule, adds them to playlists, posts comments, and reads the channel's own statistics.

Where data is kept. Access tokens are stored only on the owner's computer. No data is sold or shared with anyone, or sent to any server other than Google's.

Google API Services. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. It also follows the YouTube Terms of Service and the Google Privacy Policy.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions.
